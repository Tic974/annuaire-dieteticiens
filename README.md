# Diététiciens libéraux de La Réunion

Annuaire des diététiciens libéraux adhérents : carte des communes, liste par commune, trombinoscope et fiches détaillées.

Site statique publié avec GitHub Pages. Page unique (`index.html`) : données, photos et contours des communes sont intégrés à la page.

- Carte : [Leaflet](https://leafletjs.com/), fond © contributeurs [OpenStreetMap](https://www.openstreetmap.org/copyright)
- Contours des communes : IGN Admin Express via geo.api.gouv.fr (Licence Ouverte)

## Mise à jour annuelle

Les données viennent du formulaire « Annuaire » de l'association. La page est régénérée à partir de l'export CSV des réponses, puis republiée ici.
